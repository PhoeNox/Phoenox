# Memory Index

- [Code Engineering Principles](feedback_code_engineering_principles.md) — IOSP, KISS/YAGNI, domain/IO separation, no inline construction, rename instead of comment (no doc blocks, no issue/ADR refs), error handling; apply on any coding task
- [Code Style Preferences](feedback_code_style.md) — no underscore prefix on private fields; boolean operators at start of continuation lines
- [No Prettier](feedback_no_prettier.md) — never add Prettier to projects; ESLint only, strip it from scaffolds
- [Placement Rules](feedback_placement_rules.md) — CLAUDE.md for universal rules only, code standards live in memory; user/style global, project context project-scoped
- [Analyze vs Implement Distinction](feedback_plan_before_implement.md) — "find improvements" = present findings only; don't execute changes without being asked
- [Post-Implementation Handoff](feedback_post_implementation_handoff.md) — after implementing run nothing: no tests/lint/build/typecheck/verify (user's part), no commit until approved
- [One Step At A Time](feedback_one_step_at_a_time.md) — bei geführten Abläufen in externen Systemen (Formulare, Portale) nur den nächsten Schritt zeigen, dann warten
